# DSA Playground 🚀

An interactive Data Structures and Algorithms (DSA) playground built using **Python and Flask**, where users can solve and test classic DSA problems directly from the browser.

## 🔗 Live Demo
https://dsa-playground-7vgw.onrender.com/

## ✨ Features
- Interactive input-based execution
- Problems categorized by topic
  - Arrays
  - Strings
  - Sliding Window
- Clean UI with CSS
- Deployed on Render

## 🛠 Tech Stack
- Python
- Flask
- HTML, CSS
- Render (Deployment)

## 📂 Problem Categories
### Arrays
- Two Sum
- Reverse Array
- Maximum Subarray

### Strings
- Palindrome Check
- Valid Anagram

### Sliding Window
- Maximum Sum Subarray of Size K
- Longest Substring Without Repeating Characters
